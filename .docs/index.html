NASA Hunch 2026-2027

A.C.T.S

-semi- Automated Cargo Transport System

01 / Project summary

Project overview

Project Goal

Our goal is to create a semi autonomous system that can safely transport and deliver a storage container over a long distance in a hazardous climate.

Project Requirements

  • Move a 2 ft cargo container from landing to moon base
  • Work in 1/6th gravity
  • up to 40ft travel distance
  • able to create sealed connection with base for retrieving cargo

Project details

For our project, we plan on designing a prototype vehicle that will utilize a tightening screw mechanism with high friction pads attached to the ends, similar to a common vice clamp but with the durability of the cargo taken into further consideration. To allow the robot to move we plan on using wheels similar to the design used on existing lunar robots as shown below as they are long lasting and require minimal to no maintenance. Once the clamp mechanism has attached to the cargo container, a similar mechanism also using a platform moving along screw will be used to raise the cargo container up to the robot to provide ground clearance.

02 / Design Choices

Project Research

Why we chose the parts and mechanisms we did over other commonly used options:

Vice Clamp for carrying Cargo:

  • Able to handle a larger load while having lower torque applied to the structure of the mechanism.
  • Less vulnerable to degrading in lunar dust than a mechanism with a high number of joints.
  • Only requires one motor/overall mechanically simple.
  • Low complexity mechanism for if repairs are needed.

Hollow solid tires:

  • Degrade slower than common rubber tires.
  • Provide better traction on lunar surface.
  • Do not have any joints or areas that would be rapidly degraded by lunar dust unlike tracks or robotic legs.
  • Do not need to hold pressure unlike common rubber tires.
  • Much lighter than common tires for ease of transport.

Other parts chosen and reasons why:

  • Raspberry PI for wireless communication with prototype as it can easily process information to enact a planned route without requiring wireless communication once a route is provided.
  • Rechargeable batteries so the robot does not need to be disassembled to replace them unless battery health is critical.
  • A basic solar panel array will be included so that batteries can be recharged away from the lunar base if needed.
